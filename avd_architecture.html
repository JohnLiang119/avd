AVD (All Video Downloader) 系統架構圖

全方位解析基於 Vite + Vue 3 跨平台前端、Tauri v2 (Rust) 桌面運行時與 Capacitor (Android 原生) 的高性能影音解析、多線程下載與局域網串流架構。

✨
1. 前端視圖與互動展示層 (Frontend Presentation Layer)
統一由 Vue 3 + TypeScript 構建，透過響應式 UI 與自適應元件支援桌面與行動端
Vite 8 • Vue 3.5 • Vant 4
🎨 主應用介面與控制器
App.vue
集成了影片連結解析、畫質選擇 (1080P/2K/4K/音訊)、下載佇列進度、歷史紀錄管理、Web 存取 QR Code 及深色/淺色主題切換。
Vant UI qrcode.vue 狀態反應性
📑 批次解析與下載彈窗
YouTubeBatchModal.vue
支援 YouTube 播放清單 (Playlist) 與頻道影片的遞迴平鋪解析，提供全選、自訂勾選、預估容量與一鍵佇列批次下載。
批次排程 播放清單解析
🔤 簡繁智慧字詞轉換
opencc-js
針對標題、頻道名與輸出日誌進行動態簡體轉臺灣繁體 (cn2tw)，並精確保護原繁體字（如「岳」避免被過度修正）。
在地化 繁體中文優化

判斷 isTauri() 或 Capacitor 環境，自動分流執行緒：桌面端走 Rust Sidecar，Android 端走原生 Java 插件。

listeners & Emitters

即時回調 頻寬監聽

Rclone Bridge
調度 Rclone 程序進行已下載影片背景上傳至 Google Drive 或 WebDAV，支援即時進度監控與完成通知。

lib.rs / main.rs
負責視窗生命週期、外掛註冊 (Shell, Fs, Dialog, OS)、IPC 命令處理 (start_win_local_server, stop_win_local_server)。
Tauri 2.11 Rust IPC
🌐 內嵌 HTTP 伺服器 & 串流
server.rs (tiny_http)
提供 Port 8080 局域網網頁服務、支援影片 Range 請求即時串流、分 IP 上傳速度統計 (TrackingReader) 與裝置 UA 智慧識別 (iPad, PC, 智慧電視)。
tiny_http Range 串流 速度追蹤
⚙️ Sidecar 二進制執行庫
src-tauri/bin/*
包含編譯封裝的 yt-dlp.exe (影音抽取)、ffmpeg.exe (轉碼與影音合併) 及 rclone.exe (雲端備份)。
yt-dlp ffmpeg rclone
📱 Android 行動運行時 (Capacitor + Java)
Native Android
🔌 Capacitor 橋接外掛
YoutubeDlPlugin.java
橋接 JavaScript 與 Android 原生核心，調度 Python/yt-dlp 執行庫進行影片解析、格式比對及下載調用。
Capacitor Plugin youtubedl-android
🚀 高性能下載引擎
CronetDownloader.java
基於 Google Chromium 的 Cronet 網路堆疊，支援多線程並行分塊下載、斷點續傳與極致頻寬利用。
Google Cronet 多線程加速
📡 行動端檔案與串流伺服器
LocalFileServer.java
基於 NanoHTTPD，提供手機本機 Web 檔案總管、區域網路影片播放、遠端下載任務推送、即時每秒速度監聽。
NanoHTTPD 局域網分享
🛡️ 背景保活與影音轉碼
KeepAlive & FFmpegHelper
前台服務 (Foreground Service) 防止背景下載被 Android 系統終止；FFmpeg 負責多音軌合併與格式轉換。
Foreground Service FFmpeg Native

📺 局域網客戶端 (Clients)
