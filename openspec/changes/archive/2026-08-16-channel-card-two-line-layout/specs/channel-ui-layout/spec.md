# 規格：頻道卡片雙行版面規格 (Capability: channel-ui-layout)

## 需求與行為規格 (Requirements & Behaviors)

### 1. 雙行卡片結構
- **系統必須 (SHALL)** 在已追蹤頻道卡片中採用清晰的兩行式或彈性雙層佈局。
- **第一行 (Header Row)**：
  - 左側展示頻道圓形頭貼（32px）與頻道完整標題。
  - 右側放置「啟用/停用 Switch 開關」以及「刪除 (X) 按鈕」。
- **第二行 (Footer/Detail Row)**：
  - 左側以小字（11px 灰色）展示「最新: 影片標題」，並具備充足寬度展示更多字數。
  - 右側放置「🧪 測試」圓角按鈕。

### 2. 響應式與視覺體驗
- **系統必須 (SHALL)** 確保在手機螢幕（360px~412px）與桌面版彈窗中均不產生版面破裂或橫向捲軸。
- **系統必須 (SHALL)** 點擊「測試」按鈕時，正確觸發單一頻道模擬下載並優先插隊。
