## ADDED Requirements

### Requirement: 未設定 API 金鑰時須明確告知追蹤已停止

當使用者未設定 YouTube Data API 金鑰而觸發頻道檢查時，系統 MUST（必須）明確告知「頻道追蹤因缺少金鑰而停止」，並指出可於設定中填入。

此訊息 MUST NOT（不得）與下列任何既有分支混用：

- **MUST NOT** 顯示「目前沒有新影片」—— 系統根本沒有檢查，那是假陽性。
- **MUST NOT** 顯示「無法連線至 YouTube」或其他抓取失敗類文案 —— 系統並未發出任何請求，不是連線問題，而顯示連線失敗會把使用者導向錯誤的排查方向。

移除備援後此區分格外重要：先前 API 不可用時仍有其他通道承接，使用者看到的是正常結果；現在缺少金鑰即等於追蹤完全停止，若沿用既有文案，使用者會以為一切正常而數日後才察覺。

#### Scenario: 未設金鑰時手動檢查

- **WHEN** 使用者未設定金鑰並點擊「立即檢查」
- **THEN** 系統 MUST（必須）告知追蹤因缺少金鑰而停止，並指出可於設定中填入
- **AND** 系統 MUST NOT（不得）顯示「目前沒有新影片」
- **AND** 系統 MUST NOT（不得）顯示「無法連線至 YouTube」或其他抓取失敗類文案

#### Scenario: 未設金鑰時的自動檢查不重複騷擾

- **WHEN** 未設定金鑰的狀態持續，而自動排程反覆到期
- **THEN** 系統 MUST NOT（不得）於每次排程到期時重複彈出相同提示
- **AND** 使用者 MUST（必須）仍能自頻道管理介面的持續狀態指示得知追蹤已停止

#### Scenario: 設定金鑰後恢復正常回饋

- **WHEN** 使用者填入有效金鑰後再次檢查
- **THEN** 系統 MUST（必須）恢復依既有的成功／失敗分支顯示結果
