## ADDED Requirements

### Requirement: 頻道關鍵字備份與還原相容性

系統 MUST（必須）在本地與雲端頻道備份中保存每個頻道的關鍵字清單，並在覆蓋或合併還原時恢復有效關鍵字。還原時匯入的關鍵字 MUST（必須）經過與頻道訂閱其他建立入口相同的關鍵字正規化規則。系統 MUST 同時接受未包含關鍵字欄位的舊版備份，且 MUST NOT（不得）因缺少該欄位而拒絕整份備份。

#### Scenario: 匯出含關鍵字的頻道
- **WHEN** 使用者匯出包含關鍵字設定的頻道追蹤清單至本地或雲端備份
- **THEN** 備份資料 MUST 為每個頻道保存正規化後的關鍵字字串陣列

#### Scenario: 覆蓋還原新版備份
- **WHEN** 使用者以覆蓋模式還原含有關鍵字欄位的合法備份
- **THEN** 系統 MUST 以備份中的頻道與其關鍵字清單取代目前的頻道追蹤清單

#### Scenario: 合併還原新增頻道
- **WHEN** 使用者以合併模式還原含有目前尚未訂閱之頻道的合法備份
- **THEN** 系統 MUST 新增該頻道並一併恢復其有效關鍵字清單

#### Scenario: 合併還原重複頻道
- **WHEN** 合併還原依既有「自動去除重複的 Channel ID」規則，判定備份中的頻道已存在於目前追蹤清單
- **THEN** 系統 MUST 依既有規則保留目前的頻道，並將該規則延伸適用於關鍵字：本機頻道的關鍵字清單 MUST NOT（不得）被匯入資料覆寫或與之合併

#### Scenario: 合併還原告知未套用的匯入關鍵字
- **WHEN** 合併還原完成，且其中有 N 個頻道因 Channel ID 已存在而未套用備份中的關鍵字設定
- **THEN** 系統 MUST 在還原結果提示中明確告知有 N 個頻道保留本機關鍵字設定、未套用匯入值
- **AND** N 為零時，系統 MUST NOT（不得）顯示該說明

#### Scenario: 還原未含關鍵字的舊版備份
- **WHEN** 合法的舊版頻道備份未包含關鍵字欄位
- **THEN** 系統 MUST 將該頻道的關鍵字視為空清單並依既有全量追蹤方式運作

#### Scenario: 還原時清理無效關鍵字
- **WHEN** 備份的關鍵字清單包含非字串、空白（含 Unicode 空白與零寬字元）或重複項目
- **THEN** 系統 MUST 忽略非字串與空白項目，並依頻道關鍵字正規化規則去除重複項目後完成還原
- **AND** 保留的顯示文字 MUST 為備份中第一個對應項目的原始文字

### Requirement: 還原頻道清單時的時間錨點保守處理

系統 MUST（必須）在還原頻道追蹤清單時，對每個頻道的時間錨點採取較保守（較舊）者，避免跨裝置還原把錨點推向較新的時間而造成永久漏片。以覆蓋模式還原時，若備份中某頻道的時間錨點晚於本機現值，系統 MUST（必須）保留本機較舊的錨點；若備份的錨點較舊，系統 MUST（必須）採用備份值。以合併模式新增頻道時，系統 MUST 採用備份中的錨點；合併模式遇到已存在的頻道時，系統 MUST 維持本機錨點不變。

#### Scenario: 覆蓋還原不得使本機錨點前進
- **WHEN** 使用者以覆蓋模式還原備份，且備份中某頻道的時間錨點晚於本機目前該頻道的時間錨點
- **THEN** 系統 MUST 保留本機較舊的時間錨點，MUST NOT（不得）以備份中較新的錨點取代
- **AND** 若備份中該頻道的錨點較本機為舊，系統 MUST 採用備份的較舊錨點
- **AND** 若僅有一方存在該頻道的時間錨點，系統 MUST 採用該存在的錨點；兩方皆無時 MUST 維持未初始化狀態，MUST NOT（不得）以當下時間建立錨點
