## Why

AVD 目前只在下載、頻道檢查或更新請求失敗後才讓使用者知道網路可能中斷，主畫面沒有可立即辨識的連線狀態。加入持續可見但不干擾操作的網路狀態，可讓使用者在送出工作前先理解裝置狀況，也能減少將離線誤判為 YouTube、RSS 或下載功能故障。

## What Changes

- 在非 TV 模式的主畫面「重整／清除／刪除／設定」控制按鈕列加入網路狀態元件：正常／檢查中時為精簡標籤，緊貼該列最左側，按鈕仍維持靠右對齊；不穩定／離線時於該按鈕列正上方展開全寬提示列，不與按鈕擠在同一排。
- 網路正常時以精簡綠色狀態標籤呈現；檢查中或連線不穩時使用中性色／橘色；確認離線時展開紅色提示並提供重新檢查操作。
- 將「網際網路狀態」與既有「區域網路快傳伺服器狀態」分開呈現，避免無 Internet 但 LAN 仍可用時產生錯誤暗示。
- 先製作可獨立開啟、可切換各狀態的 HTML 示意圖，確認版面後再套入正式 Vue 主畫面。
- 狀態僅供使用者判讀，不阻擋既有下載、頻道檢查、快傳或背景排程；既有錯誤處理仍是各功能的最終依據。

## Capabilities

### New Capabilities

- `network-status`: 定義主畫面網路狀態的偵測、狀態轉換、呈現方式與手動重新檢查行為。

### Modified Capabilities

（無）

## Impact

- `src/App.vue`：新增主畫面狀態元件與生命週期整合，元件併入既有「重整／清除／刪除／設定」控制列，不再獨立佔用網址輸入列上方一整列。
- `src/services/` 或 `src/composables/`：新增可測試的網路狀態判定與監聽邏輯。
- 獨立 HTML 示意圖：供版面與四種狀態確認，不納入正式執行路徑。
- 可能使用瀏覽器／WebView 的連線事件與小型連線探測；不改變既有 RSS 重試、下載重試或 LAN 快傳契約。
