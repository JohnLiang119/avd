# 變更提案：優化頻道追蹤卡片為雙行佈局 (Channel Card Two-Line Layout)

## 為什麼要做 (Why)
在目前的頻道自動追蹤彈窗中，已追蹤頻道卡片將「頻道頭像/標題/最新影片」與「【測試】按鈕、【啟用/停用開關】、【刪除按鈕】」全部排在同一橫行。
這導致右側按鈕佔用過多寬度（約佔 40% 空間），左側的頻道名稱（如「正直講...」）與最新影片標題被嚴重擠壓並提早截斷，影響使用者的閱讀與辨識體驗。

## 做什麼 (What)
優化頻道卡片的版面結構，將其調整為雙行式結構（Two-Line Layout）：
1. **第一行**：左側展示頻道頭貼與「頻道名稱」（享有更充裕的橫向空間），右側配置「啟用開關」與「刪除按鈕」。
2. **第二行**：左側展示「最新: 影片標題」（享有全寬或更長空間），右側配置「測試」按鈕。
3. 保持整體卡片簡潔、精緻與操作流暢，並支援點擊測試按鈕時直接插隊模擬下載。

## 影響範圍 (Scope)
- 前端元件/視圖：`src/App.vue` 中的頻道卡片 DOM 結構與 CSS 排版樣式。
