## Purpose

規範整個應用程式的視覺契約：介面以文字與留白傳達資訊而非圖像，同時確保每一個操作仍可被辨識、可被區分、可被觸及。極簡是為了讓重要的東西看得見，不是為了少畫幾個東西。

## ADDED Requirements

### Requirement: 介面不得以裝飾性圖像傳達資訊

介面 MUST NOT（不得）使用裝飾性的圖像、表情符號或圖示來裝點標題、說明文字或訊息。資訊 MUST（必須）由文字本身承載。

**唯一的例外是頻道頭像** —— 它不是裝飾，而是承載識別資訊：使用者以頭像在清單中辨認頻道，那是文字之外的第二個識別維度。任何其他圖像若要加入介面，MUST（必須）能說明它承載了什麼文字無法承載的資訊。

此要求涵蓋提示訊息：訊息的嚴重程度 MUST（必須）由措辭與呈現方式表達，MUST NOT（不得）倚賴表情符號作為分級手段。

#### Scenario: 瀏覽任一畫面

- **WHEN** 使用者開啟應用程式的任一畫面、彈窗或對話框
- **THEN** 畫面上 MUST NOT 出現裝飾性的表情符號或圖示
- **AND** 唯一可出現的圖像 MUST 為頻道頭像

#### Scenario: 顯示提示訊息

- **WHEN** 系統顯示成功、警告或失敗的提示
- **THEN** 該訊息 MUST NOT 以表情符號標示其嚴重程度
- **AND** 使用者 MUST 仍能自措辭分辨該訊息是成功、警告或失敗

### Requirement: 操作控制項須可辨識且不得僅倚賴游標停留提示

每一個可操作的控制項 MUST（必須）在**不與其互動的情況下**即可被看見，並可辨識其所執行的動作。

控制項的意義 MUST NOT（不得）僅由游標停留（hover）時才出現的提示文字承載 —— **觸控裝置沒有 hover**，該提示在手機上永遠不會顯示。目前四處成對的刪除按鈕正是倚賴此種提示區分彼此，那在本應用程式主要的使用裝置上等同不存在。

以單一字元作為控制項標示時，該字元 MUST（必須）與其動作有可理解的對應關係，且同一動作在全應用程式中 MUST（必須）使用同一個字元。

#### Scenario: 於觸控裝置操作

- **WHEN** 使用者在沒有游標的觸控裝置上檢視任一含操作按鈕的畫面
- **THEN** 每個按鈕 MUST 可被看見，且其動作 MUST 可被辨識
- **AND** 系統 MUST NOT 要求使用者以游標停留才能得知某個按鈕的用途

#### Scenario: 同一動作的標示一致

- **WHEN** 同一種動作出現於多個不同畫面
- **THEN** 其標示 MUST 在各處一致
- **AND** 不同的動作 MUST NOT 使用相同的標示而無其他區辨方式

### Requirement: 顏色須承載語意，不可逆的操作須可被區別

顏色 MUST NOT（不得）作為裝飾使用。介面 MUST（必須）以中性色階為主體，並保留**單一**強調色，該強調色 MUST（必須）只用於**不可逆或會造成設定永久遺失**的操作。

不可逆的操作與其鄰近的可復原操作 MUST（必須）在視覺上可區別，且該區別 MUST NOT（不得）僅由游標停留提示承載。

以多種顏色裝點介面會稀釋強調色：當藍、綠、橘、琥珀同時存在，代表危險的紅色就不再跳出來。收斂色彩因此同時是視覺上的簡化與安全上的改善，兩者不衝突。

#### Scenario: 不可逆操作與可復原操作相鄰

- **WHEN** 一個不可逆的操作與一個可復原的操作於同一列相鄰出現
- **THEN** 兩者 MUST 在視覺上可明確區別
- **AND** 該區別 MUST 於觸控裝置上生效，MUST NOT 僅倚賴游標停留提示

#### Scenario: 強調色的使用範圍

- **WHEN** 檢視應用程式中任何使用強調色的元素
- **THEN** 該元素 MUST 為不可逆或會造成設定永久遺失的操作
- **AND** 系統 MUST NOT 以該強調色裝點標題、狀態或一般按鈕

### Requirement: 視覺簡化不得縮小觸控範圍

移除按鈕的外框、背景或圖示 MUST NOT（不得）縮小其可觸控的範圍。控制項的**視覺**尺寸與其**可點擊**尺寸 MUST（必須）分開處理：視覺可以收斂，可觸及的區域 MUST（必須）維持。

相鄰控制項之間 MUST（必須）保有足以避免誤觸的間距，尤其當其中一者為不可逆操作時。

#### Scenario: 按鈕外框被移除後

- **WHEN** 某個控制項的外框或背景因視覺簡化而被移除
- **THEN** 該控制項的可觸控範圍 MUST 不小於簡化之前
- **AND** 使用者 MUST 仍能以手指準確點擊該控制項

#### Scenario: 不可逆操作與其鄰居的間距

- **WHEN** 一個不可逆操作與其他控制項相鄰排列
- **THEN** 兩者之間 MUST 保有足以避免誤觸的間距
