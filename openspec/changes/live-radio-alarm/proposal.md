## Why

使用者每天早上聽中廣新聞網的早報（06:00《早安新聞》、07:00《中廣早報新聞》），希望手機時間一到就自動開始播，不必自己解鎖、開 App、找電台。AVD 目前只有「下載後交給外部播放器」一種播放路徑，沒有任何定時或直播能力；而 Android 的節能機制使「時間到就播」**不能**靠 App 前景的計時器達成 —— 手機睡著時 WebView 早已停擺，`setInterval` 不會醒來。

## What Changes

- **新增「早報鬧鐘」（Android 手機）**：可設定多組每日觸發時間（預設 06:00 與 07:00），時間一到由系統鬧鐘喚醒裝置，以前景服務播放中廣新聞網的直播串流，並在設定的播放時長後自動停止。通知列提供「停止」操作。
- **串流來源解析**：預設於觸發時向中廣官方頻道資訊 API 取得「中廣新聞網」的即時串流網址（實測回傳 `https://stream.rcs.revma.com/fgtx07f3qtzuv`，AAC）；API 取不到時退回上次成功播放的網址，再退回內建網址。使用者可改填自訂串流網址，此時略過 API。
- **鬧鐘設定的權威來源在 Android 原生端**：鬧鐘必須在 WebView 未啟動時也能響，故時間清單、時長、來源網址皆由原生端持有；前端不另存副本，透過插件方法讀寫。
- **重開機、系統時間或時區變更後自動重新登錄鬧鐘**；鬧鐘一律登錄為「下一次」單次觸發，響完再登錄下一次。
- **偏好設定新增「早報鬧鐘」區段**：時間清單（新增、刪除、逐筆啟用）、播放時長、串流網址、試播、下一次觸發時間與上次播放結果。Windows（Tauri）端不顯示此區段。
- **失敗回報**：觸發時無網路或串流不可用，於限時重試後停止並以通知告知；失敗摘要保留於原生端，下次開啟 App 時寫入既有的錯誤紀錄。
- **新增 Android 權限**：精確鬧鐘（`USE_EXACT_ALARM` / `SCHEDULE_EXACT_ALARM`）、媒體播放型前景服務、開機完成廣播、通知（執行期請求）。

### 已做的假設（可在審閱時推翻）

- **每天**觸發，不分平假日（使用者原話「每天早上」）；星期篩選列為非目標。
- 播放採**鬧鐘語意**：使用鬧鐘音訊屬性，手機在靜音或勿擾模式下仍會響，音量跟隨系統鬧鐘音量。
- 預設播放時長 **30 分鐘**（06:00 早報約 10 分鐘、07:00 早報約 25 分鐘），每組時間可個別調整。
- 06:00 的播放尚未結束時 07:00 觸發，視為**延長**至新的結束時間，不中斷重播。
- 只提供「中廣新聞網」一個預設電台加自訂網址；其他中廣頻道（流行網、音樂網等）雖可自同一 API 取得，列為非目標。

## Capabilities

### New Capabilities

- `live-radio-alarm`: 定時播放電台直播 —— 多組每日時間的登錄與喚醒、前景播放與自動停止、來源解析與退回順序、重開機與時間變更後的重新登錄、失敗回報，以及對應的設定介面。

### Modified Capabilities

- `config-persistence`: 現行「單一真相來源的設定持久化」要求**所有**設定值透過單一儲存介面（前端 `useStorage`）讀寫。鬧鐘設定必須在 WebView 未執行時被原生端讀到，前端儲存埠做不到；故需補上一類受約束的例外 —— 「原生端為權威來源的設定」：此類設定由原生端持有、前端 MUST NOT 另存可獨立寫入的副本、且每個平台上仍只有一個權威來源。單一儲存介面的要求對其餘所有設定維持不變。

## Impact

- **Android 原生**（`android/app/src/main/java/com/mattpocock/avd/`）：新增鬧鐘接收器（鬧鐘觸發、開機完成、時間與時區變更）、媒體播放前景服務、鬧鐘排程與設定儲存類別；`YoutubeDlPlugin` 新增讀寫設定、試播、查詢狀態的插件方法；`AndroidManifest.xml` 新增元件與權限；`build.gradle` 新增 media3 ExoPlayer 依賴（可靠播放無長度的 AAC 串流）。
- **前端**：`App.vue` 偏好設定新增區段；新增服務模組封裝插件方法與純函式（時間字串驗證、「下一次觸發」顯示），純函式附 vitest 測試。
- **對外網路存取**：`www.bcc.com.tw` 的官方 API 與 `stream.rcs.revma.com` 串流；均為公開端點，不需憑證。
- **不影響**：Windows/Tauri 端與 TV 模式的既有行為、下載佇列、頻道追蹤。
- **版本進版**：依工作區規範同步七處版號並更新 `avd_s/publish_all.ps1` 預設發布說明。
