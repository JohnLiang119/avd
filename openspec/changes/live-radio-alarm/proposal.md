## Why

使用者每天早上聽中廣新聞網的早報（06:00《早安新聞》、07:00《中廣早報新聞》），希望手機時間一到就自動開始播，不必自己解鎖、開 App、找電台。AVD 目前只有「下載後交給外部播放器」一種播放路徑，沒有任何定時或直播能力；而 Android 的節能機制使「時間到就播」**不能**靠 App 前景的計時器達成 —— 手機睡著時 WebView 早已停擺，`setInterval` 不會醒來。

## What Changes

- **新增「廣播鬧鐘」（Android 手機）**：鬧鐘清單，每筆為「時刻 + 星期 + 頻道 + 時長」，時間一到由系統鬧鐘喚醒裝置，以前景服務播放該頻道的直播串流，並在設定的播放時長後自動停止。通知列提供「停止」操作。內建頻道為中廣新聞網與中廣流行網，模型另支援自訂串流頻道。
- **串流來源解析**：內建頻道於觸發時向中廣官方頻道資訊 API 依名稱取得即時串流網址（實測新聞網為 `https://stream.rcs.revma.com/fgtx07f3qtzuv`，AAC）；API 取不到時按頻道退回上次成功播放的網址，再退回該頻道的內建網址。自訂頻道直接用其網址，略過 API。
- **鬧鐘設定的權威來源在 Android 原生端**：鬧鐘必須在 WebView 未啟動時也能響，故鬧鐘清單、頻道、音量皆由原生端持有；前端不另存副本，透過插件方法讀寫。
- **重開機、系統時間或時區變更後自動重新登錄鬧鐘**；鬧鐘一律登錄為「下一次」單次觸發，響完再登錄下一次。
- **本地檔案頻道**：頻道除了電台直播，也可以是使用者自手機選取的一或多個 mp3／mp4 —— 選檔時複製進 App 私有目錄，一個頻道是一份固定順序的播放清單，鬧鐘觸發後循環播到時長結束；影片只解音訊。檔案讀不到即依失敗流程通知，不改播電台。頻道列因此新增「新增／檢視檔案／改名／移除」的介面（自訂串流網址的新增介面仍不做）。
- **股票報價頻道**：頻道可以是多支台股代號；鬧鐘時間到向富果（Fugle）行情 API 逐支抓報價，組成中文口說稿，以裝置的文字轉語音合成成音檔後由同一個播放器播放、循環到時長結束。金鑰為全域設定存原生端。全部抓不到時仍念出原因並記為失敗；部分抓不到念其餘並說明數量。
- **偏好設定新增「鬧鐘」區段**：以時間為第一層的鬧鐘卡片（展開後為星期、頻道、時長）、頻道列（每個頻道附直播鈕）、音量滑桿；試播與自我測試收於「進階」。介面遵守「正常時安靜、異常才說話」。Windows（Tauri）端不顯示此區段。
- **失敗回報**：觸發時無網路或串流不可用，於限時重試後停止並以通知告知；失敗摘要保留於原生端，下次開啟 App 時寫入既有的錯誤紀錄。
- **新增 Android 權限**：精確鬧鐘（`USE_EXACT_ALARM` / `SCHEDULE_EXACT_ALARM`）、媒體播放型前景服務、開機完成廣播、通知（執行期請求）。

### 已做的假設（可在審閱時推翻）

- 星期**可選**，預設全選、至少一天（實作後由使用者要求加入；原假設為「每天、不分平假日」）。
- **沒有總開關**：每筆鬧鐘自有開關，清單預設為空即達成「升級後不會無預警響」。
- ~~播放採**鬧鐘語意**：使用鬧鐘音訊屬性，手機在靜音或勿擾模式下仍會響，音量跟隨系統鬧鐘音量。~~
  **已推翻**（使用者要求，見 design.md D17）：鬧鐘、試播、手動直播一律走**媒體音量**；代價是靜音或勿擾模式下鬧鐘不會出聲。
- 預設播放時長 **30 分鐘**（06:00 早報約 10 分鐘、07:00 早報約 25 分鐘），每組時間可個別調整。
- 06:00 的播放尚未結束時 07:00 觸發，視為**延長**至新的結束時間，不中斷重播。
- 內建頻道為中廣新聞網與中廣流行網；其他三個中廣頻道只差一個名稱參數，自訂串流頻道的模型與播放路徑已支援，但新增頻道的介面本次不做。

## Capabilities

### New Capabilities

- `live-radio-alarm`: 定時播放電台直播 —— 鬧鐘清單（時刻、星期、頻道）的登錄與喚醒、前景播放與自動停止、按頻道的來源解析與退回順序、重開機與時間變更後的重新登錄、失敗回報、手動直播、可自行驗證的機制，以及對應的設定介面。

### Modified Capabilities

- `config-persistence`: 現行「單一真相來源的設定持久化」要求**所有**設定值透過單一儲存介面（前端 `useStorage`）讀寫。鬧鐘設定必須在 WebView 未執行時被原生端讀到，前端儲存埠做不到；故需補上一類受約束的例外 —— 「原生端為權威來源的設定」：此類設定由原生端持有、前端 MUST NOT 另存可獨立寫入的副本、且每個平台上仍只有一個權威來源。單一儲存介面的要求對其餘所有設定維持不變。

## Impact

- **Android 原生**（`android/app/src/main/java/com/mattpocock/avd/`）：新增鬧鐘接收器（鬧鐘觸發、開機完成、時間與時區變更）、媒體播放前景服務、鬧鐘排程與設定儲存類別；`YoutubeDlPlugin` 新增讀寫設定、試播、查詢狀態的插件方法，以及本地檔案頻道的選檔複製（`pickRadioAlarmFiles`，系統選檔器多選後複製至 `filesDir/radio_alarm/<channelId>/`）與副本刪除（`removeRadioAlarmChannelFiles`）；`AndroidManifest.xml` 新增元件與權限；`build.gradle` 新增 media3 ExoPlayer 依賴（可靠播放無長度的 AAC 串流）。
- **前端**：`App.vue` 偏好設定新增區段；新增服務模組封裝插件方法與純函式（時間字串驗證、「下一次觸發」顯示），純函式附 vitest 測試。
- **對外網路存取**：`www.bcc.com.tw` 的官方 API 與 `stream.rcs.revma.com` 串流（公開端點，不需憑證）；股票報價頻道另存取 `api.fugle.tw`，需使用者自行申請的 API 金鑰（`X-API-KEY`）。
- **Android Manifest**：宣告 `TTS_SERVICE` 的 `<queries>`，讓 `TextToSpeech` 在 Android 11+ 找得到語音引擎。
- **不影響**：Windows/Tauri 端與 TV 模式的既有行為、下載佇列、頻道追蹤。
- **版本進版**：依工作區規範同步七處版號並更新 `avd_s/publish_all.ps1` 預設發布說明。
